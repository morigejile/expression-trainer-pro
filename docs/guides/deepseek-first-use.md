# 新用户首次使用：配置 DeepSeek AI 分析

本手册帮助你从首次配置走到生成第一份 AI 分析报告，不需要编写代码。适用于已经安装并能打开「好好表达」的用户。

更新日期：2026-11-06。不同应用版本的入口可能略有差异；DeepSeek 的模型名称、价格与平台页面可能调整，以链接中的官方说明为准。

可随时从「帮助」→「DeepSeek 配置指南」找到本手册，也可从「设置」→「AI分析」打开首次配置指南。正文离线可读；访问开放平台和调用 DeepSeek 需要网络。

## 1. 准备账号、余额和 API 密钥

API 密钥是让「好好表达」调用你自己的 DeepSeek 账号的凭据。能在 DeepSeek 网页或 App 聊天，不代表已经完成 API 配置。

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录账号。
2. 在平台检查 API 可用余额；没有可用余额时，按平台提示按需充值。先按少量试用的需要准备即可，不必预先购买大量额度。API 按输入、输出用量计费，具体见 [官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。
3. 进入 [API keys 页面](https://platform.deepseek.com/api_keys)，按页面提示创建密钥。名称可填写「好好表达」，方便以后识别用途。
4. 复制生成的完整密钥，稍后粘贴到应用的「API 密钥」字段。密钥只填入自己信任的应用，不要放进聊天、截图或反馈材料；疑似泄露时在开放平台撤销并重新创建。

平台页面若调整，可从开放平台首页寻找 API keys 和余额入口。密钥申请与接口说明见 [DeepSeek 首次调用 API](https://api-docs.deepseek.com/zh-cn/)。

## 2. 确认本地语音识别可用

DeepSeek 用于分析表达内容；把录音转成文字由本机语音识别模型完成，两者需要分别准备。

1. 在应用右上角点击「···」→「设置」→「语音识别」。
2. 如果已有模型显示「使用中」，保持当前选择即可。
3. 如果尚无可用模型，先安装一个可用模型，再选择使用。首次中文试用可选「Zipformer Small CTC 中文 INT8」；已有其他可用模型时无需为了本手册更换。
4. 等待安装、校验和加载完成，确认模型显示「使用中」后再开始录音。

下载失败时检查网络和磁盘空间，再在此页重试。模型准备好以后，本地录音、转写和历史回放可以离线使用；调用 DeepSeek 仍需要网络。更多排查说明可在「帮助」→「问题与反馈」查看。

## 3. 在应用中添加 DeepSeek 配置

打开右上角「···」→「设置」→「AI分析」，在「模型配置」区域点击「配置新模型」。

按下表填写：

| 界面字段 | 填写内容 | 说明 |
|---|---|---|
| 配置名称 | `DeepSeek 日常练习` | 自己能辨认即可，不影响模型调用 |
| 服务提供方 | `DeepSeek` | 选择内置 DeepSeek 项 |
| 模型名称 | `deepseek-flash` | 本手册采用官方当前列出的模型名，完整输入，不加引号或空格 |
| 服务地址 | `https://api.deepseek.com/v1/chat/completions` | 选择 DeepSeek 后由应用固定显示，无需修改 |
| API 密钥 | 第 1 步复制的完整密钥 | 只粘贴密钥本身，不加 `Bearer` 前缀 |

**注意模型名称：当前应用新建配置可能预填 `deepseek-chat`，请手动替换为 `deepseek-flash`。** 官方当前列出的模型名见 [首次调用 API](https://api-docs.deepseek.com/zh-cn/)；官方已公告旧名 `deepseek-chat` / `deepseek-reasoner` 停用安排，见 [V4 发布说明](https://api-docs.deepseek.com/zh-cn/news/news260424/)。不要把配置名称「DeepSeek 日常练习」填入模型名称。

官网示例中的 `base_url` 与应用显示的完整请求地址写法不同，这是正常的。使用内置 DeepSeek 时，保留应用地址即可，不必切到「自定义兼容服务」。

## 4. 测试、保存，再选择「使用」

1. 点击「测试连接」。应用会向 DeepSeek 发送一条简短测试请求，不发送你的训练内容；请求可能产生少量 API 用量。
2. 显示「连接成功；配置尚未保存。」后，点击「保存配置」。
3. 回到配置列表，找到刚保存的「DeepSeek 日常练习」，点击「使用」。
4. 确认这条配置显示「使用中」。

这几步作用不同：**测试连接不保存配置，保存配置不自动选中使用，选中使用也不自动开启训练后的分析。** 连接测试仅验证基本访问，第一份真实报告还需要下一步试用。

如果保存失败，保留编辑内容并重试，不要直接关闭设置。测试失败时先按后面的排查表检查，不必反复新建配置。

## 5. 开启自动分析并完成首次告知

为了结束录音后自动获得报告，在「AI分析」页顶部开启「启动AI分析」。本手册后续按自动分析流程操作。

随后点击右上角「×」关闭设置，回到应用。首次实际使用 AI 时，应用会在报告内显示数据告知；阅读并确认后，才发送本次分析请求。取消或关闭告知不会发送本次分析，你仍可查看已有的本地内容。

使用本手册的 DeepSeek 配置时，必要的转写、相关文本证据、时间与指标摘要、分析指令，以及训练框架、主题和场景会发送到 DeepSeek。针对性重练还可能使用所选目标及必要的上一轮文字与上下文；原始录音不发送给 DeepSeek。完整边界可随时查看「帮助」→「数据与隐私」。

如果希望每次自己决定是否分析，可以保持「启动AI分析」关闭，在报告中点击「分析这一次」。首次同样需要完成告知。

## 6. 完成第一次训练并确认配置成功

1. 回到首页，首次建议保持自由表达，主题、场景可以留空。
2. 点击 `start`，按提示阅读首次录音说明并允许使用麦克风，倒计时后开始讲话。
3. 讲一小段有实际内容的表达，例如一个日常选择、你的理由和相关经历。只说「你好、测试」可能被判为材料不足，无法验证诊断效果。
4. 点击结束，等待处理。首次 AI 告知若出现，阅读后确认。
5. 查看本次报告，确认有实际生成的分析摘要；如有充分依据的问题，可展开证据核对原话，并查看下一轮建议。
6. 从 `history` 打开这次记录，确认已有报告和可用录音可以重新查看。

**配置成功看的是：选中的服务能为这次表达生成可读的 AI 分析。** 不要求报告一定发现问题；「没有充分证据的问题」与「未配置、未开启、分析失败」是不同结果。录音、转写和本地统计出现，也不单独代表 AI 已经成功。

报告默认先显示一个优先问题；有其他问题时点击「更多」查看。觉得建议不适用时，先结合原文和录音判断，不必为了完成流程而照做。

## 7. 常见问题

本应用的连接测试可能只显示通用失败提示，不一定展示下面列出的 HTTP 状态码。表中的状态码用于对应 [DeepSeek 官方错误说明](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)。

| 遇到的情况 | 优先检查与处理 |
|---|---|
| 连接失败、密钥无效；官方对应 401 | 检查是否复制完整，是否带入引号、空格或 `Bearer`；确认密钥未撤销。重新输入后测试 |
| 提示 HTTP 402，或通用失败且 API 无可用余额 | 登录 DeepSeek 开放平台检查 API 余额，按需充值后重试；网页聊天可用不等于 API 余额充足 |
| 模型不存在，或格式、参数错误（如 400 / 422） | 先核对模型名称为 `deepseek-flash`、服务提供方为 DeepSeek；仍失败时可能涉及应用与服务的兼容问题，保留错误时间和脱敏信息反馈，不要随意改地址或更换密钥 |
| 超时、网络失败、服务器繁忙（如 500 / 503） | 检查网络，稍后重试；若持续失败，通过「帮助」→「问题与反馈」排查。不需要为了 AI 请求失败重新录制已有表达 |
| 请求过于频繁（429） | 等待后再试，避免连续点击测试或重试 |
| 测试成功，但录音结束后没有自动分析 | 确认已保存配置、点击「使用」、显示「使用中」，并开启「启动AI分析」；检查首次告知是否已确认 |
| 「启动AI分析」无法开启 | 先保存完整的模型与密钥配置，再选为「使用中」；尚未选中有效配置时开关不可用 |
| 没有字幕或没有可用转写 | 检查麦克风权限、实际输入设备及「语音识别」页；整段识别模型要等录音结束后才转写。这与 DeepSeek 密钥是不同问题 |
| 有转写，但提示材料不足 | 改用一段完整、有实际内容的表达再试，不必重配密钥；材料不足是分析结论，不等于接口失败 |
| 连接成功，但报告提示失败或返回内容无效 | 测试请求与报告分析要求不同。保留本地记录，使用报告中的恢复入口；持续失败时反馈应用版本、模型名称与脱敏错误信息。不要把连接成功当成报告一定成功 |
| 修改模型或服务后不再自动分析 | 保存模型、服务或地址变更后，需要重新开启「启动AI分析」 |

## 8. 后续费用与配置管理

- 在 DeepSeek 开放平台查看余额和用量；报告、重练和重新分析可能产生新的调用费用，历史报告的正常打开不触发新的分析。
- 暂时不需要自动分析时，关闭「启动AI分析」；本地录音、转写、历史和已有报告仍可使用。
- 密钥更换后，在该配置的「···」→「编辑配置」中输入新密钥，测试并保存。编辑时密钥框为空不代表丢失：界面提示「已设置；留空保留」时，不填就会保留原密钥。
