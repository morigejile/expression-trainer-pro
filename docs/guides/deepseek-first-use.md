# AI 分析配置指南

接入 AI 大模型后，「好好表达」可以根据你的练习生成分析报告，帮你找到最值得练的地方。

- **找到优先改进的问题**。比如结论说得太晚，或几条理由之间的关系没讲清楚。
- **回看判断依据**。在报告里查看对应的原话，结合录音判断建议是否适合你。
- **带着目标重练**。从报告里的具体问题开始下一轮练习，在有足够证据时，对照前后表现看有没有改善。

正文可离线阅读。访问服务商平台或使用在线模型需要联网。

## 1. 选择服务并准备配置

打开「设置」→「AI分析」→「配置新模型」，在「服务提供方」选择你要使用的服务。配置名称可以自己起，模型名称填写该服务使用的模型标识。

| 服务提供方 | 需要准备的信息 |
|---|---|
| DeepSeek | 模型名称和 API 密钥，服务地址由应用填入 |
| 自定义兼容服务，例如通义千问（阿里云百炼）、豆包（火山方舟）、Kimi（月之暗面） | 所选平台提供的兼容 Chat Completions 请求地址、模型名称和 API 密钥 |

如果所选服务需要开通 API，请在对应平台确认 API 已开通且有可用额度。填写「API 密钥」时，只粘贴密钥本身。请勿在聊天、截图或反馈材料中分享密钥。疑似泄露时，在服务商平台撤销并重新创建。

## 2. 测试、保存并启用配置

1. 点击「测试连接」。应用会向所选服务发送一条简短测试请求，请求可能产生少量 API 用量。训练内容仅在实际分析时发送。
2. 显示「连接成功；配置尚未保存。」后，点击「保存配置」。
3. 回到配置列表，找到刚保存的配置，点击「使用」，确认它显示「使用中」。
4. 想在录音结束后自动生成分析时，在「AI分析」页顶部开启「启动AI分析」。也可以在报告中点击「分析这一次」，按次发起分析。

测试、保存、选择「使用」和开启自动分析是独立操作。保存失败时，可在设置中保留编辑内容并重试。连接失败时，可先查阅下方的常见问题。

## 3. 配置示例 · DeepSeek

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录账号。使用网页或 App 聊天的用户也需要单独准备 API 凭据和可用余额。
2. 检查 API 余额，按需充值。用量计费说明见 [DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。
3. 进入 [API keys 页面](https://platform.deepseek.com/api_keys)，创建密钥。名称可填写「好好表达」，方便以后识别用途。

在「配置新模型」中填写以下信息，然后按第 2 节测试、保存并选择「使用」。

| 界面字段 | 填写内容 | 说明 |
|---|---|---|
| 配置名称 | `DeepSeek 日常练习` | 可自行命名 |
| 服务提供方 | `DeepSeek` | 选择内置 DeepSeek 项 |
| 模型名称 | `deepseek-flash` | 完整输入模型标识 |
| 服务地址 | `https://api.deepseek.com/v1/chat/completions` | 选择 DeepSeek 后由应用固定显示，无需修改 |
| API 密钥 | 刚创建的完整密钥 | 只粘贴密钥本身 |

如果应用预填了 `deepseek-chat`，可改为示例中的 `deepseek-flash`。可用模型名称见 [DeepSeek 首次调用 API](https://api-docs.deepseek.com/zh-cn/)。

## 4. 生成第一份 AI 分析报告

本地语音识别负责把录音转成文字，所选 AI 服务负责分析表达内容。首次录音前，打开「设置」→「语音识别」，确认有模型显示「使用中」。尚无可用模型时，先安装并选择一个模型，例如「Zipformer Small CTC 中文 INT8」。

1. 回到首页，首次建议保持自由表达，主题、场景可以留空。
2. 点击 `start`，按提示阅读首次录音说明并允许使用麦克风，倒计时后开始讲话。
3. 讲一小段有实际内容的表达，例如一个日常选择、你的理由和相关经历。只说「你好、测试」可能被判为材料不足，无法验证诊断效果。
4. 点击结束，等待转写。若未开启自动分析，在报告中点击「分析这一次」。首次实际使用 AI 时，阅读数据告知并确认后，应用才会发出本次分析请求。
5. 在报告中查看本次表达的分析摘要，确认所选服务已生成分析。有充分证据的问题时，可以展开证据核对原话。
6. 从 `history` 打开这次记录，确认已有报告和可用录音可以重新查看。

实际分析会将必要的转写、文本证据、时间与指标摘要、分析指令和训练上下文交给所选服务处理。针对性重练还可能使用所选目标和必要的上一轮文字。原始录音留在本机。完整说明见「帮助」→「数据与隐私」。

## 5. 常见问题

连接测试可能只显示通用失败提示。使用 DeepSeek 时，可参考 [DeepSeek 官方错误说明](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)。

| 遇到的情况 | 优先检查与处理 |
|---|---|
| 连接失败或密钥无效 | 核对服务提供方和服务地址，检查密钥是否完整、是否仍有效 |
| API 额度不足 | 登录所选服务的平台查看额度或余额，按需处理后重试 |
| 模型不存在或参数错误 | 核对所选服务的模型标识。使用自定义兼容服务时，核对完整请求地址和所选模型是否支持该接口 |
| 超时、服务器繁忙或请求过于频繁 | 检查网络，稍后重试。若持续失败，通过「帮助」→「问题与反馈」排查 |
| 测试成功，但录音结束后没有自动分析 | 确认已保存配置、点击「使用」、显示「使用中」，并开启「启动AI分析」；检查首次告知是否已确认 |
| 「启动AI分析」无法开启 | 补齐所选服务需要的配置，保存后点击「使用」 |
| 没有字幕或没有可用转写 | 检查麦克风权限、实际输入设备及「语音识别」页；整段识别模型要等录音结束后才转写 |
| 有转写，但提示材料不足 | 改用一段完整、有实际内容的表达再试，不必重配密钥；材料不足是分析结论，不等于接口失败 |
| 连接成功，但报告提示失败或返回内容无效 | 测试请求与报告分析要求不同。保留本地记录，使用报告中的恢复入口；持续失败时反馈应用版本、模型名称与脱敏错误信息。不要把连接成功当成报告一定成功 |
| 修改模型或服务后不再自动分析 | 保存模型、服务或地址变更后，需要重新开启「启动AI分析」 |

## 6. 后续费用与配置管理

- 使用计费服务时，可在对应平台查看用量和余额。生成报告、重练和重新分析可能产生新的调用费用，打开历史报告不会触发新的分析。
- 暂时不需要自动分析时，关闭「启动AI分析」；本地录音、转写、历史和已有报告仍可使用。
- 密钥更换后，在该配置的「···」→「编辑配置」中输入新密钥，测试并保存。编辑时密钥框为空不代表丢失：界面提示「已设置；留空保留」时，不填就会保留原密钥。
