## Manual acceptance path

1. 悬停、点击或用 Tab 聚焦轻量锚点，展开胶囊。选择 PREP/STAR/金字塔，点击独立问号查看说明；分别尝试主题+场景、只选一项、全部留空和自定义编辑/取消。移开后收起，确认开始按钮不位移。完成一段表达，确认报告保留两项实际采用的上下文、通用分析及所选框架反馈。
2. 在同一报告选择另一框架重新分析，确认报告身份中的原训练方式不变，新反馈可查看；失败重试仍使用刚才选择的框架。
3. 从一个 Finding 选择练习范围，确认准备页继承题目/框架且单独显示目标，完成第 2 轮，再沿该目标继续至第 3 轮。
4. 展开前后证据和练习历程；重启后仍显示正确轮次。使用专门的测试记录删除中间轮，确认有删除占位、不改变后续轮次，后续仍可继续练习。

判读模型反馈时同时核对原文：完整框架、缺少一个环节、句子/片段练习、转写不完整各取样例；确认不会强迫分数、成功结果或虚构改善。未配置 AI 时仍应保留录音、转写和本地结果，并明确显示专项分析/比较不可用。
