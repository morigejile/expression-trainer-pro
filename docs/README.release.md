# 好好表达

**说一遍，看清问题，再练一遍。**

好好表达（Expression Trainer）是一款面向中文表达练习的 Windows 桌面应用，适合工作汇报、面试交流、团队提案和日常沟通。

录下一段表达，查看转写和分析，找到一个值得改进的问题，再带着目标练一遍。应用把原话、录音、建议和练习记录放在一起，帮助你从“感觉没说好”，走到“知道哪里可以改、下一次怎么练”。

**录下表达 → 查看分析 → 针对问题重练 → 对照前后表现**

## 适合什么样的练习

- **工作汇报**：练习先说结论，再交代进展、依据和下一步安排。
- **面试与经历分享**：把背景、自己的行动和结果讲清楚，让听者理解你的贡献。
- **提案与观点表达**：说明主张，用相关的理由和例子支撑判断。
- **日常沟通**：减少绕远、含糊和重复，把真正想说的意思表达出来。

可以直接自由表达，也可以选择内置题目、场景，或填写自己的练习内容。框架、主题和场景都可跳过，不必先填完表单才能开始。

## 从一次表达，到下一次改进

### 录下来，也看得见

通过麦克风开始练习，本地语音识别将讲话转为文字。使用流式识别模型时，可以边说边看到转写。结束后，录音和转写自动保存在本机，随时可以回听、核对。

### 看懂问题，也看得到依据

接入 AI 后，报告会结合本次内容与训练场景，分析组织与衔接、论点与论据、措辞等方面，并给出具体的改进建议。先看简短摘要和优先问题，需要时再展开更多发现、对应原话和证据。

本地统计还提供录音时长、转写字符数、待核查用词，以及语速与停顿的观测信息。可以查看用词所在的上下文，回放检测到的语音间隔，结合实际听感理解数据。

### 选一个问题，再练一轮

从报告中的具体问题进入针对性练习，带着同一个目标重新讲完整段表达。报告会在证据充分时对照上一轮与本轮的内容，反馈改善之处和仍需练习的地方；多轮练习可以沿历程继续回看。

例如，第一次汇报把结论放在了大量背景之后，下一轮就专门练习“先说结论，再补背景”，随后对照两次开头，观察是否更直接、更清楚。

### 留下记录，方便复盘

历史记录保留每次练习的录音、转写和已有报告，关闭应用后仍可继续查看。也可以选中两条记录并排阅读，比较可比指标的变化，回到各自的原文与录音核对。

历史对比用于自主复盘；针对同一目标的连续重练，还会提供相应的 AI 变化反馈。

## 自由表达，也可以有结构地练

不需要先学会一套理论才能开始。默认自由表达；想专门练习内容组织时，可以在录音前选择框架并查看说明。

| 训练方式 | 适合练什么 | 表达思路 |
|---|---|---|
| 自由表达 | 日常沟通、自选话题 | 按自己的方式讲述 |
| PREP | 观点、判断与建议 | 观点 → 理由 → 例子 → 回扣观点 |
| STAR | 面试、经历分享与复盘 | 情境 → 任务 → 行动 → 结果与收获 |
| 金字塔 | 工作汇报、提案与复杂信息说明 | 核心结论 → 分组要点 → 逐层事实支撑 |

选择框架后，AI 分析会结合该框架给出反馈。框架用于帮助组织思路，不要求机械套用固定句式。

## 为什么适合持续使用

| 你想做什么 | 应用如何帮助你 |
|---|---|
| 把建议变成练习 | 从报告中的问题直接开始下一轮，保持明确的练习目标 |
| 判断建议是否适合自己 | 回看对应原话、录音和前后证据，核对反馈依据 |
| 快速找到本次重点 | 先看简短摘要和优先问题，需要时再展开细节 |
| 没有网络时也能练 | 相关模型准备完成后，仍可录音、转写、查看可用本地统计和历史记录 |
| 自主选择 AI 服务 | 支持 DeepSeek 及自定义兼容服务，管理多套配置，选择手动或自动分析 |

## 开始第一次练习

1. **安装并打开应用**：获取 Windows x64 安装包，运行安装程序。安装版无需自行安装 Node.js，也无需通过 npm 启动。当前主要在 Windows 11 x64 上验证，详细范围见[平台支持说明](support-matrix.md)。
2. **准备语音识别**：打开右上角「··· → 设置 → 语音识别」。已有模型显示「使用中」时可以沿用；否则按提示安装并选择模型。首次模型下载需要联网，录音时需要允许麦克风访问。
3. **按需接入 AI 分析**：在「设置 → AI分析」中填写服务配置，测试、保存并选择「使用」。自动分析默认关闭；开启「启动AI分析」后可在练习结束时自动分析，也可以在报告中按次发起分析。
4. **讲一段真实内容**：从自由表达开始，选择一个近期经历、工作进展或需要说明的观点，结束后回看转写和录音。生成 AI 报告后，可以选择一个具体问题继续练。

**第一次练习完成后，你应得到一条可从历史中重新打开和回放的本地记录。** 无需配置 AI，也能完成录音、转写和保存；有分析需求时再接入即可。

详细操作见 [AI 分析配置指南](guides/deepseek-first-use.md)。指南以 DeepSeek 演示，并说明如何为通义千问、豆包、Kimi 等平台提供的兼容接口填写配置；实际可用性取决于所选接口与模型。应用内的「帮助」也可随时打开这份指南。

## 数据与隐私

| 你关心的数据 | 如何处理 |
|---|---|
| 录音、转写与分析结果 | 保存在本机，关闭应用不会自动删除；可在历史中回看或主动删除 |
| 语音识别与基础统计 | 在本机执行，所需模型准备完成后可离线使用 |
| 远程 AI 分析内容 | 向所选服务发送必要的转写、相关证据、时间与指标摘要和训练背景；针对性练习还可能使用必要的上一轮文字和练习目标，首次分析前说明数据范围并征求确认 |
| 原始录音 | 当前 AI 分析不向远程服务发送原始音频 |
| 已有报告 | 保留生成时的结果，切换 AI 配置不会自动重写；查看历史报告不会再次发起分析 |
| 诊断信息 | 由你主动导出，不含密钥、音频或逐字稿；打开反馈入口不会自动提交诊断 |

首次模型下载及远程 AI 分析需要联网，远程调用可能产生服务商费用。完整数据说明可在应用内「帮助 → 数据与隐私」查看。

反馈用于辅助练习：转写和 AI 判断可能有误，用词命中、停顿次数也不直接等于表达问题。建议结合原话、录音和实际沟通目的判断。

## 常见问题与反馈

| 遇到的情况 | 可以先做什么 |
|---|---|
| 麦克风不可用 | 检查系统麦克风权限、设备连接和默认输入设备 |
| 模型下载失败 | 检查网络与可用磁盘空间，到语音识别设置重试；此前可用的模型会保留 |
| 没有自动生成 AI 分析 | 确认配置已保存并选择「使用」，且「启动AI分析」已开启；首次使用还需确认数据告知 |

更多帮助见应用内「帮助」。反馈问题或建议时，可进入「帮助 → 问题与反馈」，说明应用版本、操作步骤、预期结果和实际现象；排查运行问题时，可主动导出脱敏诊断信息。
