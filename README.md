# 好好表达

**说一遍，看清问题，再练一遍。**

一个面向中文口语表达的本地桌面训练应用。通过录音与转写、带证据的分析报告和针对性练习，帮助你回看自己的表达，找到下一次值得练习的重点。

可以直接开始自由表达，也可以选择 PREP、STAR 或金字塔框架。语音识别和基础分析在本机完成；配置并启用 AI 后，可以获得进一步的诊断与练习建议。

> 当前处于内部开发与测试阶段。本文介绍当前源码的能力，实际安装包可能不同。产品名称正在统一，部分窗口或安装信息仍显示旧名称。

## 核心特点

### 随时开始，也可以带着框架练

直接讲话即可开始一次训练。框架、主题与场景都是可选准备，不必先填写一整套表单。

- **自由表达**：记录一次想法、解释或日常发言。
- **PREP**：练习清楚地提出观点、给出理由和例子。
- **STAR**：练习讲述经历、行动与结果。
- **金字塔**：练习先给结论，再分层组织信息与支撑。

主题与场景可以使用本地预设或自行填写；选择后按本次训练保存，方便日后复盘。

### 结合原话和录音，理解每条建议

录音结束后，在同一份报告中查看逐字稿、本地指标与可用的 AI 分析。问题可以展开，回到关联原文和证据片段，并结合录音判断建议是否适用。

本地指标提供观察线索，AI 负责解释和建议。材料不足或只能有限分析时，报告会说明限制；不会用空缺数据补出一个分数。

### 一次专注一个问题，把建议变成练习

从报告选择一个问题，带着目标重新讲完整表达，保留本轮目标、前后证据与练习历程。

练习反馈只围绕所选目标判断；前后材料不足以比较时，会说明无法可靠判断，不把每一轮都写成“有所进步”。

### 保存每次训练，随时回来复盘

录音、逐字稿与已有报告保存在本机，重启后仍可从训练历史打开和播放。可以选择两次记录对照指标与各自证据，也可以明确删除不再需要的记录。

已有报告保留生成时的结果快照。切换 AI 配置不会自动重写历史报告。

### 本地优先，AI 由你配置和启用

识别模型准备完成后，本地录音、语音识别、基础分析与历史回放可离线使用。AI 支持多组配置，可连接 OpenAI、DeepSeek、Ollama 或自定义 OpenAI-compatible 服务。

AI 是否出网取决于实际服务地址；发送训练内容前遵循应用中的数据告知和启用流程。

## 训练流程

```text
准备：直接开始，或选择框架、主题与场景
  ↓
表达：倒计时后录音，可暂停、继续和结束
  ↓
回看：保存训练，查看逐字稿、回放与分析报告
  ↓
选择：找到一个值得继续练习的问题
  ↓
再练：带着目标再次表达，查看反馈与练习历程
```

使用流式识别模型时，录音过程中会显示转写；整段识别模型在结束后转写。当前普通录音期间不持续请求实时 AI 反馈，AI 分析主要发生在录音结束后或主动分析时。

## 开始使用

当前以源码运行方式为主。主要开发与验证环境为 **Windows 11 25H2+ x64**；其他平台的实际支持范围见[支持矩阵](docs/support-matrix.md)。

### 1. 准备环境并启动

需要 Git、Node.js **24.20.x**、npm **11.19.x**，以及系统提供的 `tar`。录音还需要可用的麦克风与权限。

```powershell
git clone https://github.com/morigejile/expression-trainer-pro.git
cd expression-trainer-pro

node --version
npm --version
npm ci
npm start
```

精确版本、依赖安装规则与验证方法见[开发与验证](docs/development.md)。

### 2. 准备语音识别模型

首次使用需要下载并校验识别模型。当前技术默认是 Zipformer Large，也可在语音识别设置中安装和选择 Zipformer Small 或 Paraformer。应用还接入了可选的 SenseVoice 整段识别，其下载与实机验收仍有待完成项。

首次下载和解包需要网络及磁盘空间。模型独立保存在安装目录外，Windows 默认位置为：

```text
%APPDATA%\expression-trainer-pro-models
```

模型文件不进入 Git；已有模型缓存可复用，应用更新不会隐式切换模型。模型与安装边界见[开发文档](docs/development.md#asr-模型)。

### 3. 按需配置 AI

从右上角「···」→「设置」→「AI分析」添加配置，填写模型与所需凭据，测试连接、保存后选择「使用」；内置 DeepSeek / OpenAI 的服务地址由应用固定。自动分析需要单独开启「启动AI分析」；首次实际分析的数据说明按界面提示确认。

首次配置可按 [DeepSeek 新用户配置手册](docs/guides/deepseek-first-use.md) 完成账号与密钥准备、应用设置和第一份 AI 报告验证。

首次打开会显示可跳过的快速开始，关闭后后续启动不再自动弹出。完整手册也内置于「帮助 → DeepSeek 配置指南」，AI 设置页提供同一指南入口；正文可离线阅读。

| 服务类型 | 使用方式 |
|---|---|
| OpenAI / DeepSeek | 配置对应服务的模型与 API Key；费用及可用性以服务方为准 |
| Ollama | 连接本机或自建 Ollama 服务，推理资源需求取决于模型和硬件 |
| 自定义兼容服务 | 填写 OpenAI-compatible 服务地址、模型及所需凭据 |

没有配置 AI 时，仍可使用本地录音、转写、基础分析和历史回放；AI 诊断与练习比较会说明不可用原因。连接测试成功不代表所有分析场景或反馈质量均已验收。

### 4. 完成第一次训练

1. 在首页直接开始，或先选择框架、主题和场景。
2. 首次录音阅读数据说明并授权麦克风，倒计时结束后开始表达。
3. 说完后结束录音，等待保存与本地分析；AI 是否自动分析取决于配置和启用状态。
4. 查看报告、展开证据并回放，判断哪些建议值得采用。
5. 从一个问题继续练习，或进入训练历史重新打开记录。

## 数据与隐私

| 数据或操作 | 当前处理方式 |
|---|---|
| 录音、逐字稿与训练结果 | 普通训练自动保存在本机；关闭应用不会自动删除，可在历史中明确删除 |
| 语音识别与基础分析 | 在本机运行，所需识别和语音活动检测模型首次使用时需要准备 |
| AI 分析 | 当前链路不向远程 AI 发送原始录音；可发送逐字稿、证据、指标、质量信息与分析上下文 |
| AI 的网络访问 | 取决于所选服务的实际地址；本地服务与远程服务的数据去向不同 |
| 诊断导出 | 由用户主动导出，不包含密钥、文件路径、音频或逐字稿；反馈入口不会自动提交诊断 |

具体数据边界以应用告知、[产品需求](docs/product/requirements.md)和[当前实现](docs/architecture/current.md)为准。

## 当前状态与限制

当前源码已接入录音与保存恢复、本地识别、报告与证据回看、历史对比、结构化训练和针对性练习。M4 的真实 AI 反馈质量、部分交互与最终制品验收仍在进行中，详见[M4 里程碑](docs/milestones/m4-structured-training.md)。

- **识别与定位有误差。** 转写、语音区间和播放定位受模型能力与输入质量影响，不等同于精确词级时间戳。
- **分析需要结合原话判断。** 规则命中不必然是表达问题，AI 建议也可能误判；当前不提供未经校准的雷达分数。
- **对比有明确范围。** 历史对比提供可靠指标变化与两侧报告、证据的复盘；任意两次表达的问题语义自动对应尚未实现。
- **验证结论有适用范围。** 当前已有特定设备和有限样本的验证，不能外推所有驱动、硬件或长期稳定性。
- **源码能力与公开发布分开。** 配置版本仍为 `1.0.1`；当前源码变化不代表已作为新安装包交付。公开发布还需处理模型再分发许可、签名与相应制品验证。
