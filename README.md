# 好好表达

**说一遍，看清问题，再练一遍。**

好好表达是一款面向中文口语表达的桌面训练应用。录下一次表达，结合逐字稿、录音和分析报告回看问题，再选择一个目标继续练习。

你可以直接开始自由表达，也可以带着 PREP、STAR 或金字塔框架练习。语音识别和基础统计在本机完成；按需配置 AI 后，可获得进一步的诊断、建议和针对性练习反馈。

> **当前处于内部开发与测试阶段，主要在 Windows 11 x64 上开发与验证。** 本文介绍当前源码，已有安装包可能尚未包含全部变化。真实 AI 反馈质量和最终制品验收仍在进行中。

## 适用场景

- **整理观点**：把一个想法讲出来，回看观点、理由和例子是否清楚。
- **讲述经历**：练习面试或工作复盘中的经历描述，检查行动和结果是否交代完整。
- **准备汇报**：练习先给结论，再分层组织信息与支撑。
- **日常复盘**：保存一次表达，结合原话和录音，找到下一轮值得练习的重点。

框架、主题和场景都可跳过，不必先填完表单才能开始。

## 核心能力

| 你想完成什么 | 应用提供什么 |
|---|---|
| 留下一次真实表达 | 录音、暂停与继续、本地语音转写，结束后自动保存训练记录 |
| 理解自己的表达 | 在报告中查看逐字稿、本地指标；启用 AI 后查看问题、相关原文与具体建议，并结合录音判断 |
| 带着方法练习 | 自由表达，以及 PREP（观点、理由、例子、重申观点）、STAR（情境、任务、行动、结果）和金字塔框架 |
| 把建议变成下一轮练习 | 从报告中的一个问题进入针对性练习，重新讲完整表达，查看该目标的前后证据和反馈 |
| 回看练习过程 | 保存练习目标与轮次，重启后继续查看历程；从历史打开记录、回放或选择两次记录对比 |
| 自主选择 AI 服务 | 管理多组 OpenAI、DeepSeek、Ollama 或自定义 OpenAI-compatible 配置，选择手动或自动分析 |

### 一次训练如何进行

```text
直接开始，或选择框架、主题与场景
                  ↓
          录音表达 → 结束并保存
                  ↓
     回看逐字稿、录音和本地指标
                  ↓
     按需使用 AI，查看问题与建议
                  ↓
       选择一个问题 → 重新讲一遍
                  ↓
     查看目标反馈、前后证据与练习历程
```

使用流式识别模型时，录音过程中显示转写；整段识别模型在结束后转写。普通录音期间不持续请求实时 AI 反馈，分析主要发生在录音结束后或手动触发时。

## 快速开始

当前以源码运行方式为主。以下步骤面向 **Windows 11 25H2+ x64**；其他平台尚未形成支持承诺，详见[支持矩阵](docs/support-matrix.md)。

### 1. 启动应用

准备 Git、Node.js **24.20.0**、npm **11.19.0**、系统 `tar`，以及可用的麦克风。版本依据见 [`.nvmrc`](.nvmrc) 和 [`package.json`](package.json)；完整环境说明见[开发文档](docs/development.md#环境与安装)。

在 PowerShell 中运行：

```powershell
git clone https://github.com/morigejile/expression-trainer-pro.git
cd expression-trainer-pro
npm ci
npm start
```

启动后应看到应用首页。首次打开会显示可跳过的快速开始，也可随时从「帮助」重新查看。部分窗口或安装信息仍可能显示旧名称「宇宙无敌表达训练」。

### 2. 准备本地语音识别

1. 打开右上角「···」→「设置」→「语音识别」。
2. 已有模型显示「使用中」时，可沿用当前模型；否则先安装一个可用模型，再选择使用。
3. 等待下载、校验和加载完成，再开始录音。

当前提供 Zipformer Small、Zipformer Large 和 Paraformer 流式识别模型，技术默认是 Zipformer Large。SenseVoice 为可选整段识别模型，其下载与实机验收仍有待完成项。

首次安装模型需要网络和磁盘空间。模型不随源码仓库提供，Windows 默认缓存位置为：

```text
%APPDATA%\expression-trainer-pro-models
```

已有缓存可复用，应用更新不会隐式切换模型。所需模型准备完成后，本地录音、转写、基础分析与历史回放可离线使用。

### 3. 完成第一次表达

1. 在首页直接开始，或先选择框架、主题与场景。
2. 首次录音按提示阅读数据说明并授权麦克风，倒计时后开始表达。
3. 讲完后结束录音，等待保存与本地分析。
4. 查看逐字稿、本地指标并播放录音；进入训练历史，确认能重新打开这条记录。

**完成后，你应得到一条可重新打开和回放的本地训练记录。** 无需配置 AI 即可完成以上流程。

### 4. 按需启用 AI 分析

打开「···」→「设置」→「AI分析」，添加配置，填写模型与所需凭据，测试连接、保存后选择「使用」。

| 服务类型 | 需要准备什么 |
|---|---|
| OpenAI / DeepSeek | 对应服务的模型名称与 API Key；内置服务地址由应用固定，费用及可用性以服务方为准 |
| Ollama | 可连接的本机或自建 Ollama 服务，以及已准备好的模型 |
| 自定义兼容服务 | OpenAI-compatible 服务地址、模型名称及所需凭据 |

自动分析默认关闭。配置完成后，可以在报告中手动分析；若希望录音结束后自动分析，需单独打开「启动AI分析」。首次实际使用 AI 时，按界面提示确认数据范围。

首次配置可跟随 [DeepSeek 配置指南](docs/guides/deepseek-first-use.md)完成。应用内「帮助 → DeepSeek 配置指南」提供同一份手册，正文可离线阅读。

获得 AI 报告后，先结合原文和录音判断建议；如有值得练习的问题，从该问题进入「重新练习」，带着目标再讲一遍完整表达。前后材料不足以可靠判断时，反馈会说明限制。

## 数据与隐私

| 数据或操作 | 当前处理方式 |
|---|---|
| 录音、逐字稿、训练记录与分析结果 | 保存在本机；关闭应用不会自动删除，可在训练历史中明确删除记录 |
| 语音识别与基础分析 | 在本机执行，首次使用前需要准备所需模型 |
| AI 分析内容 | 可包含本次逐字稿、相关证据、指标、质量信息与必要上下文；针对性练习还可能包含目标和必要的上一轮材料 |
| 原始录音 | 当前 AI 分析链路不向远程 AI 发送原始音频 |
| AI 数据去向 | 取决于实际服务地址；使用远程服务时，必要的分析内容会发送到该服务 |
| 诊断信息导出 | 由用户主动操作，不包含密钥、绝对路径、音频或逐字稿；打开反馈入口不会自动提交诊断 |

已有报告保留生成时的结果，切换 AI 配置不会自动重写历史报告。具体数据边界见应用内告知、[产品需求](docs/product/requirements.md)和[当前实现](docs/architecture/current.md)。

## 当前限制

- **识别与播放定位可能有误差。** 转写、语音区间和定位受模型与录音质量影响，不等同于精确词级时间戳。
- **指标和 AI 建议需要结合原文判断。** 规则命中不必然构成表达问题；AI 可能误判、重复诊断或遗漏条件。当前不提供未经校准的雷达分数，整体报告质量仍待验收。
- **历史对比有范围。** 可查看两次记录的可比指标变化、两侧报告与证据，尚未实现任意两次表达之间的问题自动对应。
- **平台与设备验证有限。** 现有证据来自特定 Windows 设备和有限样本，不能据此承诺其他平台、所有麦克风或最低硬件性能。
- **源码能力与安装包交付分别验证。** 当前报告与重练流程、失败重试和最终制品仍有验收工作；公开发布另需处理模型再分发许可、签名与相应制品验证。详见 [M4 剩余工作](docs/milestones/m4-structured-training.md#remaining-work-and-blockers)。

## 常见问题与反馈

- **麦克风不可用**：检查系统权限、设备连接和其他应用占用。应用使用系统默认输入设备，更换设备请在系统设置中操作。
- **模型下载失败**：检查网络和磁盘空间，到语音识别设置重试；此前可用的模型会保留。
- **AI 没有自动分析**：确认配置已保存并选为当前使用，且「启动AI分析」已开启。关闭自动分析后仍可手动分析。

更多帮助见应用内「帮助」。反馈问题时，可进入「帮助 → 问题与反馈」，主动导出诊断信息并打开「问题和建议文档」。请说明应用版本、操作步骤、预期结果和实际现象；分享截图或其他材料前检查是否包含私人内容或密钥。
